### broodsugar's claude · May 5, 13:00 HKT, 2026

Added `Wallet.seed() -> bytes` (the PyO3 binding's missing surface). Returns the 32 secret-key bytes the wallet was constructed from — same value `Wallet::from_seed` would round-trip through. The upstream Rust `auki_identity::Wallet::seed` was always there; the binding never wired it. Surfaced 2026-05-05 by BoosterApp Claude as a blocker for [deliverable #7](https://www.notion.so/3565c8e96592809fb674f769d826c1de) (sidecar libp2p integration): `auki_network.cluster.spawn(seed=...)` builds the swarm via `PeerIdentity::from_seed(seed)`, NOT `from_wallet`, so Python consumers rooted in a wallet (the typical pattern: `Wallet::from_seed(load_or_mint_seed(...)).derive_child("peer/v1")`) need a way to extract the *derived* peer seed bytes to hand to `cluster.spawn`. Without this method, the swarm's PeerId would not match the wallet-derived peer identity that operators put in `cluster.json`, and libp2p Noise would reject every dial. Implementation is one line — `PyBytes::new_bound(py, &self.inner.seed())` — but the docstring is substantive, walking through the cluster.spawn integration pattern and flagging the secret-bytes sensitivity. **Sibling docstring updates land in the same PR** to remove the trap that caused this miss in the first place: `auki_network.cluster.spawn` (in [`auki-network-py/src/lib.rs`](../auki-network-py/src/lib.rs)) and `auki_network::cluster_runtime::ClusterRuntime::spawn` / `::from_swarm` (in [`auki-network/src/cluster_runtime.rs`](../auki-network/src/cluster_runtime.rs)) now explicitly say "this `seed` is the *peer* seed, not the wallet seed" with the wallet-rooted invocation pattern shown inline. 3 new Rust-side smoke tests (`wallet_seed_round_trips_for_root_wallet`, `wallet_seed_round_trips_for_derived_child`, `wallet_seed_returns_32_bytes`) bringing Rust count to 8; 5 new Python-side tests (round-trip on root + derived, length pin, differs-across-derivations, plus `wallet_seed_round_trips_for_root_wallet`) bringing Python count to 18. The derived-child round-trip test pins the property the BoosterApp ansuz path relies on: `Wallet::from_seed(parent.derive_child(label).seed()).peer_id() == parent.derive_child(label).peer_id()`. Will land in v0.0.15 alongside any other small follow-ups; BoosterApp deliverable #7 unblocks against v0.0.15.

### broodsugar's claude · May 4, 18:00 HKT, 2026

Crate created — PyO3 bindings for a tiny slice of the Auki SDK. Stepping-stone Python package that exposes exactly three primitives so Boosterapp's Python sidecar can implement the [`/api/info` v0.0.11 shape](../../docs/control-api.md) ahead of the full `auki-py` MVP (libp2p Swarm + async runtime — separate, larger track per the [ansuz milestone plan](https://www.notion.so/3565c8e96592809fb674f769d826c1de)). The exposed surface: `load_or_mint_seed(path) -> bytes` (wraps [`auki_identity::load_or_mint_seed`](../auki-identity/src/seed.rs)); `Wallet.from_seed(seed).derive_child(label).peer_id()` (wraps [`auki_identity::Wallet`](../auki-identity/src/lib.rs) plus the canonical libp2p PeerId encoding from [`auki_network::PeerIdentity::from_seed`](../auki-network/src/lib.rs)); `app_instance.derive() -> str` (wraps [`auki_network::app_instance::derive`](../auki-network/src/app_instance.rs)). PyO3 0.22 with the `Bound<...>` API; `abi3-py38` so one wheel works across Python 3.8+. Built via `maturin` — `pyproject.toml` next to `Cargo.toml` declares maturin as the PEP 517 backend. `crate-type = ["cdylib", "rlib"]` so `cargo test` can drive the bindings via `Python::with_gil`; the production extension build gates `pyo3/extension-module` behind a default Cargo feature so the runtime-link mismatch between `cargo test` and `maturin develop` doesn't bite. Error mapping is one-to-one with the upstream Rust crates: `SeedError::Io` / `DeriveError::Io` → `OSError`; `SeedError::InvalidLength(n)` → `ValueError` (carries the offending length); `DeriveError::NoNetworkInterfaces` / `NoSuitableMac` → `RuntimeError` with the variant name in the message so containers can branch. **Out of scope by design** — no async / Tokio / libp2p Swarm; no signing / verification / creation certs; no WASM target. Those land in the full `auki-py` crate later. Tests: 5 Rust-side smoke tests in [`src/lib.rs`](src/lib.rs) covering module-build-and-import, deterministic peer-id derivation, wrong-length seed rejection, the `#[pyfunction]` round-trip seam, and a locked-vector shape pin; 13 Python-side tests in [`python_tests/test_basic.py`](python_tests/test_basic.py) covering all three APIs end-to-end including a Unix-only `0o600` mode check, container-tolerant `app_instance.derive` test, and the cross-language locked vector for `Wallet.from_seed(b'\x03' * 32).derive_child("peer/v1").peer_id()` that should match the parallel Rust agent's `auki-network` test byte-for-byte. Workspace `Cargo.toml` updated to include the new crate. New dev-dep on `tempfile`. PyPI publishing punted — distribution is `pip install git+...#subdirectory=` for now; will revisit once the full `auki-py` MVP ships.
