# auki-sdk

Use `AukiPeer` to sign in, connect to peers, and exchange data inside your app.
Use `AukiDomains` and `AukiDomainData` to [work with Domain data](../../docs/how-to/domain-data.md)
through the same User/App credential, without starting a peer.
Use `AukiDmsTasks` to [run native compute handlers](../../docs/how-to/run-compute-tasks.md)
from Rust or Python with DMS leases and renewable task data access.

Start with [Connect two peers](../../docs/tutorials/first-peer.md), then see the
[API and configuration reference](../../docs/reference/networking.md).
