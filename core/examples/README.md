# Networking examples

[Portable Echo](portable-echo/README.md) sends a message to another peer and
receives the same bytes back. Run it in Rust, Python, Web, or Swift.

Start with [Connect two peers](../../docs/tutorials/first-peer.md), then
[use a custom protocol](../../docs/how-to/protocols.md).

[Core Explorer](core-explorer/README.md) combines read-only Domain metadata,
portals, poses and stored data with optional authenticated Echo networking and
an idle Python robot. It includes explicit loopback fixtures.
