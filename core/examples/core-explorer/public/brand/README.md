# Local Auki brand assets

This example adapts the Auki Labs design kit's canonical tokens and official
wordmark. The interface remains dark-first with a light reading surface.

- Display: **Space Grotesk**, the design kit's open-licensed fallback.
- Body and controls: **DM Sans**.
- Fonts are bundled locally; there are no runtime Google Fonts/CDN requests.
- Each family's SIL Open Font License is included under `fonts/`.
- The licensed TT Firs Neue files are **not redistributed** in this public example.

Open font sources: Google Fonts' `ofl/spacegrotesk` and `ofl/dmsans` directories
(https://github.com/google/fonts). Keep their accompanying license notices when
redistributing these assets. Auki's logo remains its brand identity, not an
endorsement of derivative applications.
