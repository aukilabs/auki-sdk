# Glossary

*Coming soon — content to be drafted in a follow-up card.*

This page will expand on [`GLOSSARY.md`](https://github.com/aukilabs/auki-sdk/blob/develop/GLOSSARY.md) in the repo with prose explanations and cross-references to source code, suitable for someone new to the domain.

Terms expected to be expanded here:

- **Peer**, **peer_id** — the libp2p network identity
- **Session**, **session_id** — per-process boot identity
- **App**, **app_id** — application identity
- **Domain** — cluster participation context
- **Log** — peer-owned data product
- **Manifest** — log metadata pinning identity to content
- **Registry** — content-addressed catalog of sensors/clocks/frames/detectors
- **Frame** — spatial reference frame
- **Clock** — temporal reference
- **Catalog row** — wire-level resource announcement
- **Materialization** — local copy of a remote peer's log
- **Sensor kind** / **sensor type** — the closed/open taxonomy

Until then, see `GLOSSARY.md` for the authoritative one-line definitions.
