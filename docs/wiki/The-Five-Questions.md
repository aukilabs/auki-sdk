# The Five Questions

*Coming soon — content to be drafted in a follow-up card.*

The architectural backbone of the Auki protocol: any node should be able to answer five questions about any other node.

- **Identity** — who am I?
- **Spatial** — where did this happen?
- **Temporal** — when did this happen?
- **Networking** — how do I talk to you?
- **Tokenomics** — how do I compensate you?

This page will frame the SDK's implementation of each question — which crates address which, what's implemented vs. aspirational, and how a consumer composes them.

Until then, the [top-level README](https://github.com/aukilabs/auki-sdk/blob/develop/README.md) has the per-question summary.
