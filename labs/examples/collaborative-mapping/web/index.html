How this experiment works

Both maps live in your browsers. Authenticated snapshots travel through WSS relays. Names are exact and case-sensitive simulated Portal identities scoped to this demo session. All portals have the same fixed heading and size, so one shared portal establishes translation. This is not a claim that real-world names establish spatial alignment.

The combined map uses the frame of the lexicographically smaller Peer ID. Each peer keeps ownership of its original placements. Conflicting shared portals separate the views until you correct their positions or remove a conflicting portal from your own map. Synthetic map snapshots are readable by authenticated peers admitted in this Domain. Session matching selects a partner; it does not create a private read ACL.

Use Stop before closing a tab to await relay cleanup. Reloading starts a new map; no map is saved to a Domain Server.
